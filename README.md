# Manual QA Testing — ClientBase

## 📌 Project Overview

This project demonstrates my hands-on experience with Manual QA testing using the ClientBase web application.

The project includes test case design, functional testing, negative testing, regression testing, and defect reporting.

## 🧪 Testing Scope

The following areas were tested:

- Main Page
- Login
- Registration
- UI elements
- Form validation
- Email validation
- User authentication
- Navigation and links
- Positive and negative scenarios

## 📋 Test Cases

The test cases were created to verify expected application behavior across different scenarios.

Test cases include:

- Test Case ID
- Test scenario
- Test steps
- Test data
- Expected result
- Pass/Fail result
- Bug ID
- QA notes

The complete test case documentation is available in:

`Test-Cases/Manual QA ClientBase TestCases.xlsx`

## 🐞 Bug Reports

Defects discovered during testing are documented separately with detailed reproduction steps.

Each bug report includes:

- Bug ID
- Summary
- Environment
- Preconditions
- Steps to reproduce
- Expected result
- Actual result
- Severity
- Priority
- Status
- Related test case

### Bug Report Categories

- `Bug-Reports/Main/`
- `Bug-Reports/Login/`
- `Bug-Reports/Registration/`
