# BUG-003 — Registration Form Does Not Submit with Valid Credentials

## Summary

The registration form does not respond when submitting valid registration data. The user remains on the registration page and no confirmation or error message is displayed.

## Environment

- Application: ClientBase
- Page: Registration
- Browser: Chrome
- OS: Windows
- Test Case: RP-002

## Preconditions

User is on the ClientBase Registration page.

## Steps to Reproduce

1. Open the ClientBase Registration page.
2. Enter First Name: `Bob`
3. Enter Last Name: `Marley`
4. Enter Email: `UnregisteredEmail@gmail.com`
5. Enter Password: `Bob123!`
6. Check `I have read Terms and agreements`.
7. Click the Submit/Register button.

## Expected Result

The user should be successfully registered and redirected to the appropriate page.

A confirmation message should be displayed indicating that a confirmation email was sent to:

`UnregisteredEmail@gmail.com`

## Actual Result

Nothing happens after clicking the Submit/Register button.

The user is not registered, there is no redirect, and no confirmation or error message is displayed.

## Severity

High

## Priority

High

## Status

Open

## Test Case

RP-002 — Verify if user can register into the app with valid credentials
