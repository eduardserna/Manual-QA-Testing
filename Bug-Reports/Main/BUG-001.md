# BUG-001 — "Start now" Button Generates Incorrect Registration URL

## Summary

Clicking the "Start now" button generates an incorrect registration URL containing a duplicate `/v1` path.

## Environment

- Application: ClientBase
- Browser: Chrome
- OS: Windows
- Starting URL: https://clientbase.pasv.us/v1

## Preconditions

User is on the ClientBase main page.

## Steps to Reproduce

1. Open https://clientbase.pasv.us/v1
2. Locate the "Start now" button.
3. Click the "Start now" button.
4. Observe the URL in the browser.

## Expected Result

The user should be redirected to:

`https://clientbase.pasv.us/v1/user/register`

## Actual Result

The user is redirected to:

`https://clientbase.pasv.us/v1/v1/user/register`

The `/v1` path segment appears twice.

## Severity

Medium

## Priority

High

## Status

Open

## Test Case

MP-023

## Evidence

The URL after clicking "Start now" contains the duplicated `/v1` path segment.
