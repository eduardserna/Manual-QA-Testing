# BUG-002 — No Error Message Displayed for Invalid Login Credentials

## Summary

When a user attempts to log in with invalid credentials, the login attempt is rejected, but no error message or authorization feedback is displayed.

## Environment

- Application: ClientBase
- Page: Login
- Browser: Chrome
- OS: Windows
- Test Case: LP-003

## Preconditions

User is on the ClientBase Login page.

## Steps to Reproduce

1. Open the ClientBase Login page.
2. Enter an invalid email:
   `InvalidEmail@gmail.com`
3. Enter an invalid password:
   `InvalidPassword`
4. Click the Login/Submit button.

## Expected Result

The user should remain logged out and a clear error message should be displayed indicating that the email or password is invalid.

## Actual Result

The user remains logged out, but no error message or authorization feedback is displayed.

## Severity

Medium

## Priority

Medium

## Status

Open

## Test Case

LP-003 — Verify user can't log in to the app with invalid credentials
